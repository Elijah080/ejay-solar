# Elijah HTML Project

This workspace contains a static portfolio website, with pages for school, profile, restaurant, and solar system content.

## Open the project

You can either:

- Open `index.html` directly in a browser, or
- Run a local static server in the project folder and visit http://localhost:8000

## Example server command

```bash
cd "c:\Users\user\New folder"
python -m http.server 8000
```

## Pages included

- `index.html` — portfolio homepage
- `admissions.html` — school admission form
- `Elijah table.html` — school timetable
- `elijah.web development/elijah.html` — profile page
- `elijah.web development/elijah resturant.html` — restaurant page
- `solar.html` — solar system explorer

## Publish with GitHub Pages

Upload the project files and the `IMAGES` folder to a public GitHub repository, keeping the folder structure intact. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)` folder, then save. GitHub Pages will publish the site at the URL shown on that settings page.
